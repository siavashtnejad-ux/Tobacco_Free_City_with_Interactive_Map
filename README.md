# Tobacco-Free City with Interactive Map

An interactive web application that helps residents and visitors discover tobacco-free locations throughout the city.

## Project Goal

The goal of this project is to promote healthier urban environments by making smoke-free public spaces easy to find through an accessible interactive map.

## Planned Features

* Interactive map of tobacco-free locations
* Search and location filtering
* Location details and categories
* Responsive design for desktop and mobile devices
* Clear and accessible user interface

## Project Status

This project is currently under development.
